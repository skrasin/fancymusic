# COP17 Yerevan — музыка шоу «UNITED VOICES — MOTHER EARTH»

Мультимедийное представление для COP17 — 17-й Конференции сторон Конвенции ООН
о биологическом разнообразии. Ереван, площадка конференции,
**18 октября 2026** (конференция идёт 19–30 октября). Живая музыка, видео, танец.
Роль: музыкальный продюсер.

Концепция шоу — авторская, получена 10.09.2026. Здесь — музыкальное решение под неё.
