# COP17 Yerevan — музыка шоу

Шоу для COP17 (17-я Конференция сторон Конвенции ООН о биологическом разнообразии),
Ереван, Green Zone, 19–30 октября 2026. Живая музыка, видео, танец.
Роль: музыкальный продюсер.
