# Задача: сбор Telegram-каналов с i-m-i.ru под жанры FANCYMUSIC

## Цель
Собрать полный/максимально полный список Telegram-каналов из каталога
https://i-m-i.ru/sources/telegram (335 каналов, 34 страницы) с фильтром по
жанрам, релевантным лейблу FANCYMUSIC: классика / академическая музыка,
современная (contemporary), арт, экспериментальная музыка, джаз.

## Контекст / что уже сделано
Первый проход был сделан через chat-агента (web_search + web_fetch) и
уперся в техническое ограничение: **robots.txt сайта блокирует запросы
с query-параметрами** (`?page=N`, `?genres=X`), поэтому пагинация и
жанровые фильтры недоступны для автоматического обхода через этот
инструмент. Доступны только:
- статичная первая страница листинга без параметров;
- страницы жанровых тем `/themes/{slug}` (без query-параметров);
- отдельные карточки каналов `/sources/telegram/{slug}` — доступны
  бо́льшую часть времени, но не все запросы проходят стабильно
  (часть карточек тоже возвращала ROBOTS_DISALLOWED без видимой
  системности — возможно rate-limit, а не строгий запрет).

**Важно:** один найденный через поисковый индекс сниппет (канал
ЗАДРОТПОП) при прямой проверке страницы оказался **неверно описан** —
поисковый кэш показывал контент, не совпадающий с реальной страницей.
Это значит, что данные, полученные только через поиск (без прямого
запроса страницы канала), нужно перепроверять.

Есть также общий разбор по темам (не жанр, а тег) `Telegram-чаты`:
`https://i-m-i.ru/sources/telegram?tags=telegram-chats` (17 источников) —
там встречаются джаз-смежные чаты (например, DIGITAL JAZZ | Маркет).

Прямого жанра/тега «арт» на сайте нет — придётся собирать по ключевым
словам в описаниях (искусство, арт-директор, современное искусство,
выставка и т.п.) среди общего каталога, а не через жанровый фильтр.

## Рекомендуемый план для Claude Code

1. **Скрипт сбора** (Python, `requests`/`httpx` + `BeautifulSoup`):
   - Обойти 4 жанровых URL из таблицы выше постранично
     (`?genres={slug}&page={n}`), пока не кончатся карточки.
   - Для каждой карточки канала спарсить: название, ссылку на страницу
     сайта (`/sources/telegram/{slug}`), число подписчиков, описание,
     затем зайти на страницу карточки и вытащить `t.me/...` ссылку
     (она не всегда видна в листинге, но есть на странице канала).
   - Дедуплицировать по slug.
2. **Уважать сайт**: выставить внятный User-Agent, добавить паузы между
   запросами (1–2 сек), не долбить сайт параллельными запросами.
   Проверить `https://i-m-i.ru/robots.txt` перед стартом — если там
   явно прописан запрет на автоматический сбор данного раздела, лучше
   ограничиться `/themes/{slug}` страницами и карточками каналов
   поштучно, либо запросить у сайта доступ к данным иначе.
3. **Свести** результат с уже собранными двумя подтверждёнными и пятью
   предположительными каналами выше — предположительные перепроверить
   автоматически (они должны попасться в обходе жанровых фильтров).
4. **Экспортировать** в CSV/таблицу с колонками: название, t.me-ссылка,
   подписчики, жанр(ы), краткое описание, автор/лейбл-принадлежность —
   в формате, совместимом с существующей Google-таблицей Telegram-каналов
   Сергея (docs.google.com/spreadsheets/d/1-HSqqLFV8dCqc6MokEzOzfRBWZVH0OyUshsyqjsL3TY).
5. Финальный шаг — ручная сверка top-20 по релевантности жанрам
   FANCYMUSIC (классика, авангард/эксперимент, джаз) перед началом питчинга.
