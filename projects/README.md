# Проекты

Один каталог на материал — релиз, лендинг, презентацию, таблицу.
`slug` латиницей в kebab-case.

```
projects/{slug}/
  raw-materials/    — всё присланное как есть + meta.yml с фактами
  output/           — готовые файлы: .md, .docx, .pdf, .xlsx, .pptx
```

Текстовый исходник всегда `.md` — из него собираются `.docx` и `.pdf`.

Готовые веб-страницы лежат отдельно, в `docs/`: на GitHub Pages уезжает
только этот каталог. Страницы релизов — `docs/releases/{slug}/`.
