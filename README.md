# fancymusic

PR-агент лейбла [FANCYMUSIC](https://fancymusic.ru): пресс-релизы для СМИ,
посты для соцсетей и свёрстанные страницы релизов с предпрослушиванием.

## Как устроено

| Что | Где |
|---|---|
| Инструкция агенту | `CLAUDE.md` |
| Дизайн-система: токены, шрифты, компоненты | `brand/`, живая спецификация — `/design/` |
| Шаблоны текста, соцсетей и страницы | `templates/` |
| Материалы и тексты по релизам | `releases/{slug}/` |
| Опубликованные страницы (GitHub Pages) | `docs/` |

## Форматы на выходе

- `press-release.md` — источник правды по тексту
- `press-release.docx` / `.pdf` — генерируются из него по запросу, для рассылки
- `docs/releases/{slug}/index.html` — страница с обложкой, плеером и всеми блоками
- `social.md` — посты под Telegram, Instagram и VK

## Публикация

Пуш в `main` с изменениями в `docs/` или `brand/` запускает workflow `.github/workflows/pages.yml`
и выкладывает страницы на GitHub Pages. Ссылка на релиз:
`https://skrasin.github.io/fancymusic/releases/{slug}/`.

## Новый релиз

Скинуть агенту сырые материалы (био, инфо о релизе, ссылки на предпрослушивание
и соцсети) и сказать, нужны ли посты для соцсетей. Дальше — по пайплайну
из `CLAUDE.md`.

## Разовая настройка GitHub Pages

Pages включается вручную один раз: **Settings → Pages → Source: GitHub Actions**.
Автоматически (`enablement: true`) не выходит — токену workflow не разрешено
создавать Pages-сайт. После включения каждый пуш в `main` публикует `docs/`.
