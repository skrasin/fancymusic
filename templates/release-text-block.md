# Текстовый блок релиза

Сводный текст для Bandcamp, сайта и рассылки. Образец —
`projects/georgy-orlov-davydovsky-arkady-pikunov-30-kapsul`.
Сначала русская версия, после `__` — английская, с той же структурой.
Разделитель частей — строка `__`.

```
{{АРТИСТ}} - {{НАЗВАНИЕ}}

Послушать: {{ССЫЛКА}}

{{ОПИСАНИЕ — эпиграф, стих или короткий лид, если есть}}

{{АННОТАЦИЯ — 2–4 абзаца}}

{{АВТОР ТЕКСТА, если подписан}}
__

{{ТРЕКЛИСТ — для академики: Композитор — Произведение (год)}}

{{Исполнитель: инструмент — по строке на человека}}

Запись: …
Сведение, мастеринг: …
Обложка: …
Фото: …
__

{{EN: всё то же в том же порядке}}

Recorded by: …
Mixed, mastered by: …
Cover by: …
Photo by: …
```
