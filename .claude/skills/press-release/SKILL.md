# Пресс-релиз FANCYMUSIC

Полные правила тона, структуры и вёрстки — в `CLAUDE.md` в корне репозитория.
Прочитать его перед работой. Здесь — только порядок действий.

## 1. Разобрать материалы

Определить `slug` (латиница, kebab-case: `artist-release-name`), создать
`projects/{slug}/raw-materials/` и сложить туда присланное как есть.

Заполнить `raw-materials/meta.yml` по образцу `templates/meta.yml`. Каждый факт —
только из материалов. Чего нет — `[УТОЧНИТЬ]`, цитаты нет — `[ЦИТАТА]`.
Ничего не додумывать: ни жанр, ни дату, ни состав участников.

## 2. Задать один вопрос

Если в `meta.yml` остались `[УТОЧНИТЬ]` — спросить про самый критичный из них,
одним вопросом, а не списком. Критичность по убыванию: повод для инфоповода →
дата выхода → ссылка на предпрослушивание → жанр → цитата.

Отдельно, один раз в начале работы над релизом: нужны ли посты для соцсетей
или только пресс-релиз.

Если блок «О лейбле» в `brand/BRAND.md` всё ещё `[УТОЧНИТЬ]` — согласовать
формулировку и записать её туда, чтобы больше не спрашивать.

## 3. Написать тексты

- `projects/{slug}/output/press-release.md` — по структуре из `CLAUDE.md`,
  на основе `templates/press-release.md`
- `projects/{slug}/output/social.md` — на основе `templates/social.md`,
  если соцсети нужны

Один финальный вариант, без «вот три версии на выбор».

## 4. Сверстать страницу

Скопировать `templates/release-page.html` в `docs/releases/{slug}/index.html`
и заполнить плейсхолдеры. В блоке предпрослушивания оставить ровно один
вариант — встроенный плеер площадки или `<audio>` с локальным превью.

Стили в шаблоне не править: цвета и типографика меняются только через
`brand/design-tokens.css`.

Добавить строку релиза в список на `docs/index.html`.

## 5. Проверить

- в готовых текстах не осталось незакрытых `{{ПЛЕЙСХОЛДЕРОВ}}`
- все `[УТОЧНИТЬ]` либо закрыты, либо явно перечислены пользователю
- страница открывается, обложка и плеер на месте, нет горизонтальной прокрутки
- `./tools/sync-tokens.sh`, если менялись токены

## 6. Опубликовать

Закоммитить и запушить в `main`. Сообщить пользователю итоговую ссылку
`https://skrasin.github.io/fancymusic/releases/{slug}/` и список оставшихся
`[УТОЧНИТЬ]`.

DOCX и PDF собирать из `press-release.md` только по запросу — скиллами
`docx` и `pdf`.
